# 转写层闸门看不见丢失的否定词：一个预注册的不可能性演示与两个 Qwen 模型的实测行为

**范围声明**：42 条构造的口语指令 + 42 条正向镜像指令、两个 Qwen2.5 模型（3B-Instruct fp16、7B-Instruct-AWQ）、文本层错误注入（不是真实 ASR）、提议的（未执行的）工具调用。
所有数字 **EXPLORATORY**；四个 pilot 均预注册，判定按预注册规则。第一版短报告在发布前对抗评审中 **FAIL**（`KILL_ARGUMENT_round1.md`）：
它把"闸门失明"当作测出来的发现，而裁决指出这在文本层输入下是设计上的必然。本版按裁决重写：**先说清不可能性，再报行为**。

## 一句话

在这组构造卡片里，把否定词删掉后的转写有 **7/42 对与一条合法正向指令逐字相同**（gold 相反），任何只看转写和工具 schema 的闸门在**这 7 对**上原则上无法恢复原意；另有 11 对只差一个 but/and，其余 24 对文本差异更大，这 35 对只作行为观察。
两个 Qwen 模型的实测行为是照可见文本执行（否定删除后 41/42 与隐藏原意不一致；正向镜像 39–42/42 正确）。所测的可选布尔 wrapper 在这组构造集上拦下了 97.6–100% 的正向镜像。
本文建立的是**可能性**（这类碰撞存在且模型会照做）；真实 ASR 里这类碰撞的发生频率与部署代价**未知**。

## 这份报告能回答什么、不能回答什么

- 能：在 7 对逐字相同的输入上，转写层（文本 + schema）闸门有没有可用的证据？——没有（不可能性，见 §2）；模型拿到这类转写后做什么？——照做（§3）；所测的那条动作形态规则在这组构造集上代价多大？——几乎全体确认（§5）。
- 不能：真实 ASR 输出上会怎样（声学、置信度、n-best 都不在输入里）；其它模型族；"便宜闸门普遍失效"这类一般结论；实体替换的伤害（两种打分器不一致，未解决）。

## 1  设计

- **卡片**：42 条指令，每条恰有一个否定词，删除后恰翻转 gold 调用里的一个可选布尔参数；gold 与"忠于可见转写的调用"由构造决定。23 个工具 schema，每卡 1–2 个干扰工具。
- **正向镜像**（P0c 新增）：同一工具、同一参数，用户确实要那个 true 的 42 条自然表述；gold = 原卡的翻转调用。
- **单编辑条件**（逐条 WER = 1/L，严格相等）：`neg_drop` 否定词删除 / `func_drop` 功能词删除 / `content_sub` 近音替换 / `other_1w` 旁人单词句尾插入 / `other_1w_mid` 同一词句内插入；**剂量条件**（WER ≈ 0.38）：`other_intent` / `other_chatter`（多词旁人片段，保存的 trials 里为 2–6 词）。
- **闸门**（系统提示）：`none`；`confirm`（点名可能的错误类型）；`confirm_generic`（只说"不确定就问"）；`spktag`（oracle 说话人标签）；`confirm_optbool`（规则：把任何可选布尔设为 true 前先问）；离线确定性版 `wrapper_optbool`。**所有闸门的输入都只有一条转写 + schema，没有音频、n-best 或置信度。**
- **打分**：预注册严格打分（所有 gold 参数须匹配）与事后宽松打分（DEVIATION：函数名 + 布尔/整数/枚举须匹配，自由字符串不计），两者都报。
- **统计**：WA = 与**隐藏原意**不一致的提议动作率（WRONG_ACTION + FLIPPED + EXTRA_CALL）；CF = 确认率；按卡配对 bootstrap 95% CI；temperature 0。Colab T4，$0。

## 2  不可能性：删掉否定词后的转写与合法正向指令无法区分

把 42 条 `neg_drop` 转写与 42 条正向镜像逐条比对：

| | 对数 |
|---|---|
| 转写**逐字相同**、gold 布尔相反（**不可能性只覆盖这 7 对**） | **7 / 42**（me3, or3, cp2, df2, bf2, ri2, su2） |
| 只差一个 but/and（文本可观察，不在不可能性之内） | 11 / 42 |
| 差异更大 | 24 / 42 |

例：`me3` 两条输入都是 "book a one on one with priya on monday at nine and add a video link"，gold 的 `video_call` 一为 false（原话有 don't）、一为 true。
对这 7 对，两模型在 `none` 与 `confirm_optbool` 下的原始输出**逐字节相同**。任何只看这两样输入的闸门都不可能在这 7 对上做出不同决定——
这不是模型的失败，是输入里没有信息。其余 35 对的文本差异是可观察的，对它们本文只报告测得的行为，不主张不可能性。

## 3  模型在可见文本上的行为（表 1；宽松打分；n = 42/格）

| 条件 | WER | 3B WA | 7B WA |
|---|---|---|---|
| clean | 0 | 7.1 | 2.4 |
| clean_pos（正向镜像） | 0 | 7.1 | 0.0 |
| **neg_drop**（与隐藏原意不一致） | 1/L | **97.6** | **97.6** |
| func_drop | 1/L | 14.3 | 4.8 |
| content_sub | 1/L | 19.0（严格 95.2） | 9.5（严格 92.9） |
| other_1w / other_1w_mid | 1/L | 21.4 / 14.3 | 9.5 / 11.9 |
| other_intent | ≈0.38 | 28.6 | 21.4 |

`neg_drop` 的 97.6% 的构成：3B FLIPPED 37、WRONG 3、EXTRA_CALL 1、CORRECT 1；7B FLIPPED 40、EXTRA_CALL 1、CORRECT 1——即 **模型基本上在忠实执行可见转写**，
而可见转写与原意相反。在 7 对逐字相同 + 11 对只差 but/and 的 18 对输入上，两模型对 neg_drop 给出翻转调用、对 clean_pos 给出正确调用的对数分别为 17 / 18 和 18 / 18。
预注册 H2（WA(neg_drop) − WA(func_drop) ≥ 40pp）：+83.3pp [71.4, 92.9]、+92.9pp [85.7, 100]——这是构造的必然（否定删除必然与隐藏原意不一致），报告它只为说明 WER 对此完全不敏感。

## 4  确认提示与说话人标签（表 2）

| 条件 | 3B confirm | 3B generic | 7B confirm | 7B generic |
|---|---|---|---|---|
| clean（42 否定卡） | 0.0 | 0.0 | 0.0 | 0.0 |
| clean_pos（42 正向卡，P0d） | 0.0 | 0.0 | 7.1 | 0.0 |
| neg_drop | 0.0 | 0.0 | 9.5 | 2.4 |
| func_drop | 0.0 | 0.0 | 2.4 | 2.4 |
| content_sub | 0.0 | 0.0 | 0.0 | 0.0 |
| other_1w / other_1w_mid | 4.8 / 0.0 | 2.4 / 0.0 | 9.5 / 2.4 | 4.8 / 2.4 |
| other_intent / other_chatter | 31.0 / 16.7 | 28.6 / 14.3 | 21.4 / 23.8 | 16.7 / 16.7 |

按 §2，neg_drop 行的低确认率**不是检测失败的证据**——它与 clean_pos 行放在一起才有意义：7B 的 confirm 提示在正向卡上确认 7.1%、在 neg_drop 上 9.5%（两组各 42 卡的汇总率，两组文本大多不同）；在 7 对逐字相同的输入上原始输出完全一致，这才是不可能性所要求的；3B 两行都是 0%。
预注册 H1（other_1w − neg_drop ≥ 25pp）不成立：+4.8pp [0, 11.9]、+0.0pp [−11.9, 11.9]。确认提示在较长旁人片段上更常发问（16.7–31.0%），但那些片段的 WER 也高约 4 倍，长度/WER/位置/内容一起变，不能归因于单一因素。
7B 在 neg_drop 下的 4 次确认都问在被翻转的参数上（个案，n = 4）。
oracle 说话人标签在 other_intent 上的 WA 降幅：3B +2.4 [−11.9, 16.7]，7B +11.9 [0, 23.8]（预注册 30pp 不成立）；clean 上 +0.0 / +2.4pp；clean_pos 上 3B −2.4pp（4.8 vs 7.1）、7B +2.4pp（2.4 vs 0.0），都在噪声内。

## 5  只看动作形态的规则：挡得住，但代价是全体确认（表 3，P0c）

| | 3B prompted | 3B wrapper | 7B prompted | 7B wrapper |
|---|---|---|---|---|
| 在 neg_drop 上确认（挡住翻转） | 0.0 | 97.6 | 2.4 | 97.6 |
| 在 clean_pos 上确认（合法请求被拦） | 0.0 | **97.6** | 0.0 | **100.0** |

规则"把任何可选布尔设为 true 前先问"：提示版几乎不被执行；确定性版按构造挡住 97.6%，但因为每张正向镜像恰恰要求那个 true，它在**这组构造集**上拦下了 97.6–100% 的合法正向请求。
这是对**这一条规则、这组集合**的代价测量，不是对"检测"的结论，也不是对任何动作级规则的一般结论；合并后的 51.2% 来自人为 1:1 配比，不是部署代价。预注册判定：CLOSE。

## 6  数据支持什么（照 result-to-claim 与对抗评审收窄后的措辞）

1. 在这 42 对构造卡片上，删掉否定词后的转写与合法正向指令 7 对逐字相同（gold 相反）；转写层闸门在**这 7 对**上没有可用证据（不可能性）。其余 35 对文本可区分，只作行为观察。
2. 两个 Qwen 模型照可见文本执行：neg_drop 与隐藏原意不一致 41/42，正向镜像正确 39–42/42。所有百分比都以这组构造集为条件，没有发生率含义。
3. 所测的两种确认提示对构造的单词错误很少发问（≤ 9.5%），在否定卡与正向卡上的代价见表 2 两行；预注册的"旁人插入 − 否定"确认率差不存在。
4. oracle 说话人标签未达到预注册的 30pp 降幅。
5. 所测的可选布尔 wrapper 在这组构造集上挡住 97.6% 的翻转，代价是拦下 97.6–100% 的正向镜像；提示版几乎不执行。真实 ASR 中这类碰撞的频率与部署代价未测。

## 7  不写的

实体替换的伤害（严格 93–95% vs 宽松 9.5–19%，未盲判）；"便宜闸门普遍失效"；"某模型忽略标签"；把 51.2% 当部署代价；任何真实 ASR / 真实执行的结论。

## 8  偏差与过程

- 打分器：严格版对自由文本过严（clean 28.6% / 16.7% 误判），事后加宽松版并报（DEVIATION）；宽松版无法测实体替换。
- P0c 第一次运行因 Colab 客户端超时作废，改流式输出后重跑，冻结哈希未变；P0d 只在正向卡上补跑三种闸门（`PREREG_P0d.md`）。
- 卡片由作者在 AI 辅助下手写、未盲检；单一模型族；仅提示级闸门。
- 评审链（均 gpt-6-sol，经 Codex CLI）：查新 PROCEED WITH CAUTION（7/10、6/10）→ 外部评审 PROCEED（6/10）→ 方案评审 REVISE（5.5/10）→ result-to-claim partial → **kill-argument 第 1 轮 FAIL（本版据此重写）→ 第 2 轮 WARN（0 条未解决、4 条部分回应均为措辞，已按 `KILL_ARGUMENT_round2.md` 的三条修改）**。
